# MediaIndex v0.1.0

**Experimental prerelease · Windows · unsigned installer**

MediaIndex v0.1.0 is the first public evaluation release of the local-first
Windows desktop application. It indexes video where it already lives, keeps
the index in a machine-local SQLite database, and provides deterministic search
and preview without a cloud account.

## Download

Use the [GitHub v0.1.0 release page](https://github.com/Lanque/MediaIndex/releases/tag/v0.1.0)
for the Windows installer and the checksums published with the final release
asset. The installer is unsigned and should be treated as evaluation software.

## Included

- recursive local folder scanning with complete SHA-256 content identities;
- FFprobe technical metadata and a machine-local SQLite index;
- offline filename and metadata search, filters, sorting, preview, and opening
  of the original clip;
- optional sampled-frame visual indexing through OpenAI, Google Gemini, or local
  Ollama;
- a local AI cost preview after **Select Footage Folder** completes its scan;
- explicit confirmation before cloud analysis, with sampled-frame, request,
  audio, and heuristic cost information;
- optional remote budgets, request accounting, resumable vision checkpoints,
  and partial/failed coverage states that preserve completed work;
- saved AI descriptions and embeddings with provider/model histories kept
  separate.

## Before you start

The desktop shell requires the Microsoft Edge WebView2 Runtime. Install
FFmpeg and FFprobe and make them available on `PATH`. For AI analysis, select
an FFmpeg path in **AI connection** or set `MEDIAINDEX_FFMPEG_PATH`; the related
FFprobe executable is resolved beside it when possible. Metadata scanning can
use `MEDIAINDEX_FFPROBE_PATH` for an explicit FFprobe path. Development also
requires the Rust stable MSVC toolchain, Visual Studio C++ build tools, and the
Windows SDK. OpenAI and Gemini analysis requires the corresponding provider
credential; Local (Ollama) requires a running local Ollama installation and its
selected models. Local scanning, deterministic search, preview, and the cost
preview do not require an API key.

Close MediaIndex and back up `mediaindex.sqlite3` before installing a newer
build. On Windows the file is typically under
`%LOCALAPPDATA%\ee.lanque.mediaindex\mediaindex.sqlite3`. Keep a separate
backup of the original footage.

## Cost and data boundaries

The local preview does not contact OpenAI, Gemini, or Ollama and does not use an
API key. It estimates the work from the local index, selected settings, and the
checked pricing catalog. The estimate is a heuristic, not a provider quote or a
guarantee of the eventual invoice; unknown pricing remains unknown.

The full original video is not uploaded. Cloud analysis receives sampled JPEG
frames and analysis prompts/context; generated descriptions, context, and AI
Search query text are sent to the selected embedding API. Optional OpenAI
timestamped transcription receives a temporary compressed speech track for the
configured analysis span. Local Ollama keeps this data on the computer only
when its configured endpoint is local.

## Known limitations

AI coverage is a sampled prefix. With the default OpenAI settings of one frame
every five seconds and a maximum of 60 frames, a long video covers roughly the
first five minutes rather than the whole clip. Fast gameplay events such as a
death, kill, or attack may fall between samples or be described too coarsely.
For short-lived events, set **Sample every (s)** to `2` or `1` and intentionally
re-analyze the clips. Denser sampling can capture more short-lived events, but
does not guarantee that a provider will recognize or label them; the frame
limit still bounds the resulting coverage.

The installer is unsigned. A signed stable release and the complete installed
Windows verification matrix are future work. The API, worker, PostgreSQL
migration, and Terraform files are cloud scaffolding; this release does not
ship a hosted service or apply AWS infrastructure.
